# Asset provenance and regeneration

All art and audio shipped in this repository are original SilkBound assets generated by `tools/generate_assets.py` using Python's standard library only. No Starbound sprites, commercial sound libraries, external fonts, marketplace packs, or user manuscript images are bundled.

The generator writes:

- a 16-pixel terrain atlas with distinct geological and construction tiles;
- original rover animation frames, two survivor portraits, a crystalline scavenger and an Administration security drone;
- a side-view salvage vessel and three biome-specific parallax backgrounds;
- a compact item icon atlas and SilkBound launcher icon;
- synthesized mono WAV ambience and short movement, impact, warning, pickup, crafting and tool cues.

Regenerate the checked-in source assets from the repository root:

```sh
python3 tools/generate_assets.py
```

The game imports and uses these PNG/WAV files directly. Terrain chunks sample the atlas; the player and threats build `SpriteFrames` from the supplied sheets; drops use the icon atlas; each destination uses its own background and looping ambience. `project.godot` and the Android export preset point to the original launcher icon.
